## 模块详细说明

### 1. GPS模块 (`gps_service.c/.h`)

```
┌─────────────────────────────────────────────────────────────────┐
│                         GPS 模块工作流程                         │
└─────────────────────────────────────────────────────────────────┘
                              │
         ┌────────────────────┼────────────────────┐
         ▼                    ▼                    ▼
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│   串口接收层    │  │   协议解析层    │  │   数据处理层    │
│                 │  │                 │  │                 │
│ • UART2中断    │  │ • 状态机解析    │  │ • 坐标转换      │
│ • 字符流接收   │  │ • $GNRMC解析    │  │ • 原点设置      │
│ • 校验和验证   │  │ • $GNGGA解析    │  │ • XY坐标计算    │
│                 │  │ • 队列缓存      │  │ • HDOP质量评估  │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

**核心功能：**
| 功能 | 函数 | 说明 |
|-----|------|------|
| 初始化 | `gps_service_init()` | 配置UART、发送GPS配置命令 |
| 数据更新 | `gps_service_update()` | 解析NMEA语句、更新位置 |
| 设置原点 | `gps_set_origin()` | 记录当前位置为坐标原点 |
| 坐标转换 | `gps_update_local_xy()` | 经纬度→本地XY坐标(米) |

**输出数据 (`gps_data`)：**
```
gps_data.latitude      // 纬度 (十进制度)
gps_data.longitude     // 经度 (十进制度)
gps_data.pos_x         // 本地X坐标 (米)
gps_data.pos_y         // 本地Y坐标 (米)
gps_data.speed         // 地面速度 (km/h)
gps_data.course        // 航向角 (度, 北为0)
gps_data.hdop          // 水平精度因子
gps_data.is_reliable   // 数据可靠性标志
```

### 2. 摄像头模块 (`camera_service.c/.h`)

```
┌─────────────────────────────────────────────────────────────────┐
│                       摄像头模块工作流程                         │
└─────────────────────────────────────────────────────────────────┘
                              │
    ┌─────────────┬───────────┼───────────┬─────────────┐
    ▼             ▼           ▼           ▼             ▼
┌────────┐  ┌──────────┐  ┌────────┐  ┌────────┐  ┌──────────┐
│ 图像   │  │  Otsu    │  │ 边沿   │  │ 中线   │  │ 状态机   │
│ 采集   │→│ 动态阈值 │→│ 跟踪   │→│ 计算   │→│ 判断     │
│        │  │          │  │        │  │        │  │          │
│MT9V03X│  │ 二值化   │  │滑动窗口│  │ 偏差   │  │直道/弯道 │
└────────┘  └──────────┘  └────────┘  └────────┘  └──────────┘
```

**核心算法：**

1. **Otsu动态阈值**
   - 统计图像中部60行的灰度直方图
   - 自动计算最佳二值化阈值
   - 适应不同光照环境

2. **边沿跟踪 (滑动窗口)**
   ```
   ←─────── 188像素 ───────→
   ┌─────────────────────────┐  ↑
   │    [搜索窗口±15像素]    │  │
   │  ←──┤  ▓▓▓▓▓▓  ├──→    │  │
   │     左边界    右边界     │  120行
   │         ↓ 预测 ↓        │  │
   │  ←──┤  ▓▓▓▓▓▓  ├──→    │  │
   └─────────────────────────┘  ↓
   ```

3. **赛道状态机**
   ```
   ROAD_STRAIGHT → ROAD_CURVE_L/R → ROAD_LOST
        ↑              │                │
        └──────────────┴────────────────┘
   ```

**输出数据 (`track_info`)：**
```
track_info.offset          // 中线偏移量 (像素, 正=右偏)
track_info.road_type       // 赛道类型 (直道/弯道/丢线)
track_info.center_slope    // 中线斜率
track_info.valid_row_count // 有效行数
```

### 3. 导航决策模块 (`nav_decision.c/.h`)

```
┌─────────────────────────────────────────────────────────────────┐
│                       决策模块工作流程                           │
└─────────────────────────────────────────────────────────────────┘

     ┌──────────────┐              ┌──────────────┐
     │ 摄像头数据   │              │  GPS数据     │
     │ camera_valid │              │  gps_valid   │
     └──────┬───────┘              └──────┬───────┘
            │                             │
            └──────────┬──────────────────┘
                       ▼
              ┌────────────────┐
              │  模式切换逻辑  │
              │                │
              │ 丢线5帧→切GPS │
              │ 恢复3帧→切CAM │
              └────────┬───────┘
                       │
         ┌─────────────┼─────────────┐
         ▼             ▼             ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐
   │ CAM模式  │  │ GPS模式  │  │ MIXED    │
   │          │  │          │  │ 模式     │
   │偏移→转向│  │航向跟踪  │  │ 自动切换 │
   └──────────┘  └──────────┘  └──────────┘
                       │
                       ▼
              ┌────────────────┐
              │   输出控制     │
              │                │
              │ steer_angle    │
              │ target_speed   │
              └────────────────┘
```

**Pure Pursuit 路径跟踪算法：**
```
                    目标路点 (tx, ty)
                         ●
                        /│
                       / │
           航向偏差→ /  │距离
                    /   │
                   /    │
    当前位置 ●────→     │
    (cx, cy)  当前航向   │
                        │
    转向角 = 航向偏差 × Kp
```

**路点管理：**
```
路径: WP0 ──→ WP1 ──→ WP2 ──→ WP3 ──→ WP4
      起点    途经点   途经点   途经点   终点
      
到达判定: 距离 < 1.0m 时切换下一路点
```

## API 快速参考

### GPS模块
```c
gps_service_init();              // 初始化
gps_service_update();            // 更新数据 (主循环调用)
gps_set_origin();                // 设置原点
gps_is_fixed();                  // 是否定位
gps_is_reliable();               // 数据是否可靠
```

### 摄像头模块
```c
camera_service_init();           // 初始化
camera_process_frame();          // 处理帧 (主循环调用)
camera_get_offset();             // 获取偏移量
camera_get_road_type();          // 获取赛道类型
```

### 导航决策模块
```c
nav_decision_init();             // 初始化
nav_add_waypoint(x,y,type,spd);  // 添加路点
nav_set_mode(NAV_MODE_MIXED);    // 设置模式
nav_start();                     // 开始导航
nav_update(&nav_input);          // 更新 (主循环调用)
// 读取: nav_output.steer_angle, nav_output.target_speed
```
